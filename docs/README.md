## 一页速查：已经定下来的结论

- **路线**：自建薄编排层，不是从零造轮子，也不是整套部署 GUI 开源项目。约 1500–2500 行自写代码，ASR / 对齐 / 字幕格式 / 正则与规则库全部复用。
- **五阶段**：抽取与识别 → 对齐与断句 → cue 级翻译编排 → 质检与回填 → 纯字幕输出。
- **自写范围**：断句、翻译编排、质检回填三段；其余复用。
- **质量基线**：用 VideoLingo 的纯字幕模式（关 dubbing）+ 同一个自有 LLM 端点跑同一素材，作为对照 SRT。
- **不做什么**：TTS、配音、烧录、mux、yt-dlp 下载、GUI 一期、多租户。
- **关键铁律**：时间码不进 LLM；每阶段 JSONL 落盘；cue.id 稳定；结构化输出 + 按 cue 粒度重试；先 CLI 后 FastAPI。
- **命名**：CueLoom（PyPI 未占用、GitHub 同名仓库 0）；`cuewright` 已被同赛道 PyPI 包占用，禁用。
