方案保存在服务端私有配置文件，不回显密钥。保存不会自动启用；编辑已启用方案后需重新启用。

访问认证

本机回环访问由后端自动认证。远端需 HTTPS 与 Bearer token；token 仅保存在本标签页 sessionStorage，不写入 URL。

LLM 连接检查
